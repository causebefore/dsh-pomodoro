## 接口影响与修复

| 插件使用面 | 上游变化及结论 |
| --- | --- |
| Cordis / Loader、schemastery、locale、UI primitives | 当前注入、effect 清理、配置解析、翻译及组件使用方式仍兼容，无需重构。 |
| settings / configForms / configEditor | 新版远程浏览器也持久化宿主设置，configForms 快照移除 mode；getSnapshot / subscribe / mutate 形式保持兼容。旧设置迁移及 configEditor 入口无需修改。 |
| connection / fetch / RPC / 认证 | isLoopback 仍可用，认证与传输实现更新；插件保留旧版仅 loopback 的配置读取降级，不向远程发送旧 /pomodoro 请求。 |
| 模块加载 / slots | 客户端更新增加发布屏障，模块工厂及插件使用的侧栏、详情 slot 仍兼容；禁用/启用实测无残留和重复入口。 |
| 安装器 / 版本约束 | 新版优先检查 engines.dsh；补充该声明与新的 settings peer 范围，保留原有兼容范围，不使用版本豁免。 |

发现并修复远程首次配置加载竞态：旧客户端在 configForms 仍为 loading 时就允许计时及离线到期结算，可能使用默认 25 / 5 分钟或错误的自动开始选项。现在等待首次宿主配置状态明确后再操作；设置 unavailable 时仍按默认值降级。新版不可用提示不再误称所有远程连接都不支持持久化。
